# ארכיטקטורה — הערות מהנדס


נגן מדיה לשולחן העבודה. מנוע mpv מנגן כל פורמט, וממשק זכוכית צף מעליו.

## מבנה

```
src/
  main/              תהליך ראשי — מנוע, חלונות, IPC
    engine/mpv.ts    הפעלת mpv ושליטה בו דרך צינור JSON
    window/player.ts זוג החלונות המודבק
  preload/           הגשר היחיד בין הממשק לתהליך הראשי
  renderer/          הממשק — React, Tailwind, אסימוני Fluent 2
  shared/api.ts      החוזה בין השניים
  legacy_services/   שישה מודולים טהורים מהגרסה הקודמת
tools/               הורדת המנוע וכלי בנייה
tests/               בדיקות מקצה לקצה
```

## למה שני חלונות

mpv מצייר לחלון משלו, וחלון Electron שקוף יושב מעליו. ניסיתי לתת
ל-mpv את ה-HWND של חלון Electron — חלון הבן שלו כיסה את כל מה
ש-Chromium מצייר, והממשק נעלם. נמדד במדידת פיקסלים, לא בהתרשמות.

ההדבקה כולה ב-JavaScript: mpv מקבל גאומטריה חדשה בזמן ריצה דרך
הצינור, וזה נוחת בדיוק.

## פיתוח

```
npm install      # מוריד גם את המנוע
npm run dev
npm test
npm run dist
```

## נתיבים ותווים

כל נתיב עובר ל-mpv כפקודת `loadfile` בצינור, ב-UTF-8 מפורש, ולא
כארגומנט בשורת הפקודה. תוכניות שקוראות argv בגרסת ANSI ממירות אותו
לדף הקוד המקומי, ושם נתיב עברי הופך לסימני שאלה — זה קרה כאן עם
`tar`. הבדיקות רצות על קובץ בשם
`סרט עברי – מבחן [2026] & רווחים ✓.mp4` בדיוק בשביל זה.

## רישיונות

mpv הוא GPL. הבנייה שאנחנו מורידים אינה כוללת קובץ רישיון, ולכן
`tools/fetch-engine.mjs` מביא אותו ממאגר המקור ונכשל אם לא הצליח.
אנחנו מפעילים את mpv כתוכנית נפרדת ואיננו מקשרים אליו.
